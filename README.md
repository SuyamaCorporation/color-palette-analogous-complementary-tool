## Color Palette Analogous & Complementary Generator

An interactive color theory tool featuring a rendered HSL color wheel. Click anywhere on the wheel to select a base hue, then use the Lightness and Saturation sliders to refine it. Five palette types are generated in real time: Analogous, Complementary, Split-Complementary, Triadic, and Tetradic.

**Tech:** Vanilla JS, HTML5 Canvas (wheel rendered with radial gradients), Tailwind CSS. **How to use:** Click the wheel to pick a hue, adjust lightness/saturation sliders, then click any color swatch to copy its hex code to clipboard. The base color preview shows the current HSL values.
